## 六、批量生成与复用

### 6.1 性能结论

- 当前单次故障树生成全流程耗时约 `**185.866`** 秒，其中 `**故障树 JSON 生成阶段**` 占比最高，为 `**90.1%**`（按已采集阶段统计）。
- 若按批量生成统计（生成`25`棵树，用时`2314`s），平均每棵树耗时 `92` 秒，平均每棵树深度为`3`层，节点数为`5`个
- 复用机制可减少约 `99%` 的重复生成开销。
- Token 消耗主要集中在 `**树生成阶段**`，占总消耗的 `**89.5%**`。
